# Identity Security Lab

This repository documents my hands-on exploration of identity security, cloud security, identity governance, security automation, and AI-assisted security engineering.

The lab began as a Microsoft Entra ID environment where I could move beyond theoretical security concepts and gain practical experience designing, configuring, testing, and troubleshooting identity and security controls.

Over time, the environment expanded from core identity and access management into authentication security, Conditional Access, privileged access, Identity Governance, data protection, hybrid identity, automation, and AI-assisted security analysis.

Rather than serving as a collection of product tutorials, this repository documents security scenarios I implemented and tested, problems I encountered, architectural decisions I made, experiments that did not necessarily lead to a final implementation, and the lessons learned throughout the evolution of the lab.

## Lab Areas

### Identity Foundation

Tenant configuration, users and groups, role-based access control, administrative roles, custom domain integration, DNS, and Microsoft 365 identity integration.

### Authentication & Conditional Access

Authentication methods, passkeys/FIDO2, Windows Hello for Business, registration campaigns, Conditional Access, authentication strengths, and phishing-resistant authentication.

### Privileged Access

Role-assignable groups, Privileged Identity Management (PIM), eligible assignments, just-in-time privilege activation, approval workflows, authentication requirements, and temporary elevation.

### Identity Governance

Entitlement Management, access packages, self-service access, approval workflows, Separation of Duties (SoD), Access Reviews, assignment expiration, and access lifecycle.

### Data Protection

Microsoft Purview Information Protection, sensitivity labels, policy publishing, information classification, encryption, and data protection controls.

### Hybrid Identity

OpenLDAP, LDAP Account Manager, directory design, users and groups, service accounts, access controls, application authentication, and experiments involving cloud identity integration.

### Security Automation

Microsoft Graph, PowerShell, APIs, tenant configuration discovery, security assessment, and automation.

### AI-assisted Security Engineering

Visual Studio Code, GitHub Copilot, AI-generated security queries and scripts, Model Context Protocol (MCP), and experiments involving AI-assisted identity security assessment.

## Project Status

This is an evolving lab. Some sections document completed and validated configurations, while others document experiments, troubleshooting, architectural investigations, or work currently in progress.

Where an experiment was not completed or a result was not fully validated, this is explicitly documented rather than presented as a completed implementation.
